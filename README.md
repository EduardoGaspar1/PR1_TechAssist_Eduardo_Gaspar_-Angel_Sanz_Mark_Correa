- Objetivo del diseño.
Diseñar una base de datos relacional que permita almacenar y gestionar de forma organizada, coherente y sin redundancias toda la información de la empresa: clientes, técnicos, departamentos, servicios, incidencias e intervenciones.

- Descripción breve del modelo.
Una empresa de servicios técnicos necesita gestionar de forma centralizada a sus clientes, que comunican incidencias sobre los servicios contratados (presenciales y online). Cada incidencia es atendida por uno (o varios) técnicos mediante intervenciones, de las que se registran la fecha, las horas dedicadas y una observación. Los técnicos pertenecen a un departamento con un turno (mañana, tarde o mixto) y un técnico responsable.
